🔐 Authentication

Pakai apikey kamu di setiap request — dua cara:

# Sebagai query parameter
curl "https://api.kamu.com/api/random/quote?apikey=YOUR_KEY"

# Atau sebagai header
curl -H "X-API-Key: YOUR_KEY" "https://api.kamu.com/api/random/quote"

Limit: 100 request/hari (free) atau unlimited (premium). Reset 00:00 WIB.

📦 Response Format

Success

{
  "status": true,
  "code": 200,
  "result": { /* data */ }
}

Error

{
  "status": false,
  "code": 401,
  "message": "Invalid API key."
}

Beberapa endpoint (qrcode, brat, ssweb, imagine, tts, nulis) langsung mengembalikan binary (image/audio), bukan JSON. Tinggal embed URL-nya di <img>/<audio>.
